# Arcane Frontier — Android downloads

This **public** repository is the download/update channel for **Arcane Frontier Beta**.

**Current status:** No public APK has been approved or released. Please do not expect an installer yet.

- **[Check the latest channel status](latest.json)** — JSON used by the Arcane Frontier launcher.
- **Releases** — will contain the separately approved Android APK (`ArcaneFrontier.apk`) and concise release notes when the first verified build is ready.
- **Source code** is developed in a separate **private** repository. No source tree, keys, tokens, private documents or player saves should ever be copied here.

The launcher compares the public release metadata against its installed version. Updates must keep the same Android package ID and signing certificate. Android still asks before installing an update. Back up your game world externally before uninstalling.

A release is only advertised after the APK passes gameplay tests, save compatibility, mobile layout and the owner's visual review. The launcher should report **no approved build yet** until that happens.
